
# StockManager 📦

Sistema de gestión de inventarios desarrollado como proyecto de portafolio para fortalecer habilidades de desarrollo de software.

## 🎯 Objetivo

Crear una aplicación que permita administrar productos, controlar existencias y registrar movimientos de inventario.

## 🚀 Funcionalidades

- Registro de productos.
- Consulta y búsqueda de productos.
- Actualización de información.
- Eliminación de productos.
- Control de entradas y salidas.
- Gestión de categorías.
- Reportes de inventario.

## 🛠️ Tecnologías

- Java
- Spring Boot
- SQL
- HTML
- CSS
- JavaScript
- Git y GitHub
